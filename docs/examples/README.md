# Worked Examples

These examples show what good use of the most important PromethOS skills looks
like in practice.

They are intentionally stored beside the relevant skill so the boundary and the
example stay together. This index exists only to make discovery easier.

## What Each Example Should Show

- the input shape that triggers the skill
- the artifact the skill should produce
- why that skill owns the decision instead of a neighboring skill

These are examples, not canonical templates. When a real task differs, preserve
the skill boundary and adapt the artifact shape to the job.
