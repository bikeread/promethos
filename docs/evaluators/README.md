# Evaluators

This directory is reserved for reusable evaluator documentation and role
definitions that sit beside the core `skills/` taxonomy.

PromethOS keeps evaluators separate from taxonomy skills on purpose:

- skills guide decisions and workflow execution
- evaluators judge quality, gaps, and evidence after or alongside that work

The first planned addition here is a multi-angle evaluator stack covering
requirements, architecture, tools and permissions, context and memory,
execution quality, and final outcome verification.

## Files

- `evaluator-stack.md`: shared orchestration model, input contract, output contract, and aggregation rules
- `requirements-and-scope-evaluator.md`
- `architecture-and-boundaries-evaluator.md`
- `tool-and-permission-evaluator.md`
- `context-and-memory-evaluator.md`
- `execution-quality-evaluator.md`
- `outcome-and-verification-evaluator.md`
